# Default inspiration photographs

Four neutral travel scenes for the discovery view: coast, mountains, autumn
nature and a quiet street. They do not represent a selected trip or live search.
Images were retrieved through the configured Unsplash API on 2026-10-23,
registered through each photo’s download endpoint, resized to local JPEG assets,
and require no credentials or live API call to display on first load.

`credits.json` records photo IDs, photographer names, original photo pages,
English alternative text and display labels. The slideshow links the active
photo to its Unsplash source and displays its photographer attribution.
