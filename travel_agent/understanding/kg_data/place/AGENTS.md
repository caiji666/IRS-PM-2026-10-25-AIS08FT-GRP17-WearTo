# KG维护入口

适用于本目录全部文件，以及为本KG进行的资料采集。

- 开始采集、追加数据或修改实现前，必须阅读 `KG_SPEC.md` 和 `data/vocabulary.json`。
- `KG_SPEC.md` 是唯一规范性文档；只能做兼容扩充，禁止为新国家另建不兼容Schema。
- 新概念先在规范扩展登记中追加定义与兼容性说明，再同步词表、实现、校验和数据；不得删除/改名旧字段、标签或改变旧ID含义。
- 事实更正按规范保留依据与旧记录；不得重置已有人工审核状态。
- 新资料写入共用CSV并逐条溯源；读取不到正文就不能标正文核验，不编造缺失事实。
- 数据修改后按规范第7节校验、测试、更新派生文件及维护记录；纯文档修改只检查一致性。
- 不运行build_seed.py覆盖现有数据；天气API尚待后续任务，不擅自追加静态天气。
- README、国家清单和示例是派生说明，不得用它们绕过或替代规范。
